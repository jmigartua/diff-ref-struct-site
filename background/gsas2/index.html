GSAS-II

GSAS-II

B. H. Toby and R. B. Von Dreele, Advanced Photon Source, Argonne. Open-source Python with Fortran kernels, successor of GSAS/EXPGUI. Read against the FullProf baseline (L012): only what GSAS-II has and FullProf lacks within the scope, in physics and in workflow, each row saying what FullProf has instead (log L014). GSAS-II sources link to the line in GitHub; FullProf sources are named in manuals/fullprof/.

Sources read. GSAS-II source at commit c13e730 and the GSAS-II-tutorials repository at commit 924e9eb, both cloned from GitHub on 2026-10-09; the help pages are cited from their Markdown sources (MDhelp/docs), from which the in-program HTML help is generated. The published tutorial and help site (advancedphotonsource.github.io/GSAS-II-tutorials) is blocked from this session and is built from the second repository, so its sources were read instead. Every GSAS-II claim below was checked against the cited lines in the clones. The FullProf side is the baseline inventory (data/study/fullprof.yml, 158 entries and its not-found list) and the material in manuals/fullprof/: the 2001 manual, FP_COMMANDS.pdf, the eleven tutorial folders and FP_tests; each candidate gap was searched for in the text of all these PDFs and in the .pcr, .irf, .inf and .bat files before being kept. A capability that both programs have in comparable form is not listed; the ones set aside that way are named in L014.

Peak shapes, instrument and peak positions

Capability What it does In FullProf Sources
Pink-beam profile A constant-wavelength histogram type 'B' for pink (wide-bandpass) beams: back-to-back exponentials convolved with a pseudo-Voigt, with α = α0 + α1·tanθ and β = β0 + β1·tanθ for X-rays (sinθ for neutrons), plus U, V, W, X, Y, Z (Von Dreele, Clarke & Walsh 2021; Von Dreele 2024). FullProf uses back-to-back exponentials ⊗ pseudo-Voigt only for TOF (Npr=9, 10); its CW profiles are Gaussian, Lorentzian, pseudo-Voigt, Pearson VII, TCH with FCJ asymmetry, split and numerical. 'Pink beam' is not found in manuals/fullprof/. Instrument profile from fundamental parameters For a CW (usually Bragg–Brentano) instrument the NIST FPA code computes peaks from Topas-style inputs (divergence, Soller angles, goniometer radius, filament, sample and receiving-slit lengths, absorption, thickness, tube tails, PSD range, incident-beam monochromator) and a source spectrum, then fits U, V, W, X, Y and SH/L to them and saves an instrument parameter file. FPA is not used inside the Rietveld fit. FullProf's resolution file (IRF) is obtained by refining a standard such as LaB6; the only geometric term is the Finger–Cox–Jephcoat axial divergence (S_L, D_L). Background

Capability What it does In FullProf Sources
Background peaks Any number of pseudo-Voigt background peaks, each with refinable position, integrated intensity, Gaussian width and Lorentzian width, added to a smooth function; meant for broad lumps such as Kapton or container scattering. FullProf models a parasitic peak as an extra phase with fixed relative intensities read from an .hkl file and a refined scale (Jbt=3, Irf=2), or absorbs humps with Debye-like terms or a background file; no free-standing refinable background peak. powderbkg.md L31–35 · HoBaCuO-HT.pcr L216–225 · FullProf_Manual.pdf, pp. 45–46
Background function fitted to fixed points, with auto-background Fixed points are placed with the mouse or generated by pybaselines (arpls or iarpls, with a log(λ) smoothing slider); Fit Background then refines the chosen function (e.g. Chebyshev with a few terms) to the points before any Rietveld cycle. The auto-background can instead be saved as a fixed background histogram subtracted point by point. WinPLOTR picks background points by hand or automatically (about √n points, "not recommended for advanced analysis") and saves them to paste into the .pcr, where they become a linear-interpolation or spline background; FullProfAPP extracts background points (method not stated). The points are not used to fit a polynomial or Chebyshev series. powderbkg.md L92–118 · powderbkg.md L63 · FPS_dec2015_WinPLOTR_TR.pdf, pp. 38–40 · FullProf_Manual.pdf, p. 78 · Exercise-LiFePO4.pdf, p. 2
Background in powers of Q, and inverse or logarithmic interpolation Besides Chebyshev and cosine series, the background function can be a power series in Q\(^{2}\) or in Q\(^{-2}\), or an interpolation through points spaced equally in 1/x or in log x (inv interpolate, log interpolate), with 1 to 36 terms. FullProf offers a polynomial in (T/Bkpos − 1), Chebyshev (up to 24 terms), cosine Fourier series, linear interpolation and cubic splines through user points; no Q-power series and no inverse or logarithmic point spacing. Size and strain broadening

Capability What it does In FullProf Sources
Gauss–Lorentz mixing of anisotropic size broadening Isotropic, uniaxial and ellipsoidal size broadening each carry an LGmix parameter that splits the size width between Lorentzian and Gaussian parts (1 = pure Lorentzian), as microstrain does: \(\gamma\) = S·mx_size + M·mx_strain, \(\sigma\)² = (S(1−mx_size))² + (M(1−mx_strain))². FullProf has a Gaussian isotropic size term (IG/GauSiz) and a mixing parameter ξ for anisotropic strain, but its anisotropic size models are Lorentzian only ("the anisotropic size is supposed to contribute to the Lorentzian"). phasedata.md L29–38 · GSASIIstrMath.py L3330–3332 · FullProf_Manual.pdf, p. 23 · FullProf_Manual.pdf, p. 21

Spherical-harmonic preferred orientation Per phase and histogram, a cylindrically symmetric spherical-harmonic orientation distribution of chosen even order, constrained to the crystal symmetry, as an alternative to March–Dollase; the fitted distribution can be checked as a ψ-scan or inverse pole figure in multiples of random distribution. Texture analysis with generalised spherical harmonics A phase-wide orientation distribution function (Bunge; Von Dreele 1997) of even order up to 34, with sample symmetry cylindrical, 2/m, mmm or none and refinable sample-orientation zeros, applied to all histograms of the phase recorded at different sample orientations; it takes precedence over the per-histogram corrections. Le Bail and Pawley fits

Capability What it does In FullProf Sources
Pawley refinement Reflection intensities are least-squares parameters refined with the cell and profile, between a Pawley dmin and dmax, with an optional penalty weight on negative intensities; reflections are created, estimated from peak heights, and negative ones reset and unflagged. Intensities thus get standard uncertainties and enter the covariance matrix; the histogram scale must be held. FullProf implements Le Bail extraction (Jbt=2: intensities iterated from the Rietveld partition, not refined); the manual names Pawley's method only as a relative of profile matching. phasegeneral.md L75–78 · phasepawley.md L12–14 · FullProf_Manual.pdf, pp. 14–15 · FullProf_Manual.pdf, p. 89

Capability What it does In FullProf Sources
Linear constraint equations and New Var parameters Four user constraint types on named parameters: Hold, Equivalence (fixed ratios), Constraint equation (Σ mᵢpᵢ = constant, removing one degree of freedom from any number of parameters, e.g. three cations on one site summing to 1 with two free) and New Var (a new refined parameter defined as a weighted sum). The least-squares engine

Capability What it does In FullProf Sources
Levenberg–Marquardt least squares with SVD The default minimiser builds the Hessian from analytic derivatives histogram by histogram, inverts it by singular-value decomposition with a zero tolerance (default \(10^{-6}\)), so near-singular directions are dropped and the parameters causing them are named, and up-weights the Hessian diagonal (Marquardt λ) when a cycle fails to lower \(\chi^2\). Alternatives: SVD without Marquardt, MINPACK leastsq with analytic or numerical derivatives (the latter to check code). Stops on Min ΔM/M (default 0.001) or Max cycles. FullProf solves the Gauss–Newton normal equations, damping shifts with class relaxation factors and code multipliers; a singular matrix stops the run and the manual advises restarting with scale factors only; Dum=2 stops when \(\chi^2\) rises. No SVD or Marquardt step is mentioned. commontreeitems.md L36–50 · GSASIImath.py L164–246 · GSASIIstrMain.py L405–436 · FullProf_Manual.pdf, pp. 42–43 · FullProf_Manual.pdf, p. 77 · FullProf_Manual.pdf, p. 16 · FullProf_Manual.pdf, p. 68
Parameter impact Ranks the parameters not being refined by the improvement in reduced \(\chi^2\) each would give if refined (Toby, J. Appl. Cryst. 57, 175–180, 2024); also callable from scripts as ComputeWorstFit. not found in manuals/fullprof/; FullProf documents a fixed refinement order (scale; zero, background, cell; positions; shape; occupancies; displacements; microstructure). mainmenu.md L85 · GSASIIscriptable.rst L317 · FullProf_Manual.pdf, p. 14
Any expression with its s.u. from the full covariance Evaluate Expression and s.u. computes a user expression of several parameters (e.g. the total amount of an element spread over sites) with a standard uncertainty propagated through the covariance matrix, so correlations are included. FullProf prints s.u.s of refined parameters and of its own derived quantities (distances, weight fractions); in the symmetry-mode output, atom-position s.u.s are propagated "neglecting the correlation between the refined amplitudes". No user expressions. mainmenu.md L87 · FullProf_Manual.pdf, p. 43 · FullProf-Tutorial-Symmetry-Modes.pdf, p. 4
Normal probability plot Error Analysis draws a normal probability plot of the weighted residuals within the limits; the slope over the central ~68 % of points (−1 to 1) is the GOF of the well-fitting points and the intercept shows bias. FullProf reports Durbin–Watson d, the Bérar factor for serially correlated residuals, Akaike and Schwarz criteria and an expected-R analysis (Ana=1); a normal probability plot is not found in manuals/fullprof/. powderparent.md L21 · FullProf_Manual.pdf, p. 45 · FullProf_Manual.pdf, pp. 61–62 · LaMnO3ref.out L796–799

Capability What it does In FullProf Sources
One project file with a data tree Everything — data, instrument and sample parameters, phases, constraints, restraints, rigid bodies, results, covariance, sequential tables, notebook — lives in one .gpx file shown as a data tree; any number of phases and histograms, limited by memory; each save during refinement keeps a numbered backup <project>.bak<i>.gpx that can be reopened. FullProf keeps model and flags in a .pcr text file, data in separate files and results in .out, .sum, .prf and other files; the .pcr is rewritten after a run (Pcr=1) or written to CODFIL.new (Pcr=2); up to 16 phases. datatree.md L5 · datatree.md L34–36 · mainmenu.md L14–15 · FullProf_Manual.pdf, pp. 8–9 · FullProf_Manual.pdf, p. 72 · FullProf_Manual.pdf, p. 87
Python scripting API GSASIIscriptable reads and writes the same .gpx files as the GUI: add histograms (real or simulated), phases, images and PDFs; set values and flags; run lists of refinement steps; add Hold, Equivalence, Equation and New Var constraints; read covariance; rank parameters. It runs without the GUI packages, e.g. on a cluster, but does not cover every GUI feature. FullProf is driven by the .pcr and the command line (fp2k code data log), WinPLOTR command files for data handling, and the FullProfAPP GUI for batches; no programming interface to FullProf is described.   • The FullProf side is limited to manuals/fullprof/ (2001 manual, FP_COMMANDS 2012–2023, tutorials up to 2025). Features of current FullProf releases not described there (e.g. the FullProfAPP manual at fullprofapp.readthedocs.io) may close some of these gaps.
  • GSAS-II's third CW profile type 'A' (back-to-back exponentials with FCJ asymmetry, getExpFCJVoigt3) is in the code but undocumented in the help, so it was not listed.
  • Papers cited by GSAS-II (Toby 2024; Von Dreele 1997, 2024; Von Dreele, Clarke & Walsh 2021; Mendenhall, Mullen & Cline 2015) were not opened.
