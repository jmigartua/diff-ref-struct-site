The brief

The brief

The founding request of 8 October 2026, organised into numbered requirements, then kept verbatim below. Ids never change; requirements added later are appended with the log entry that adds them.

What the app is

  • R01 A macOS application built with Tauri, with the look and behaviour of a Mac app: the full menu bar and the usual Mac entries (File, Edit, View, Window, Help; Preferences/Settings, Recent items, Undo/Redo, standard shortcuts).
  • R02 Its main purpose is Rietveld refinement of crystal structures from powder diffraction data, in the style of the programs in use for it: FullProf, GSAS and the commercial ones.
  • R03 Scope restricted to powder diffraction with laboratory X-rays, synchrotron radiation and neutrons.
    Working name of the brief: diff-ref-struct, “a modern FullProf, Mac version”.

Background study first

  • R04 An inventory of the programs commonly used for these refinements: what each does and how it does it.
  • R05 The brief names FullProf and GSAS as the two most used; check the five most used and study those, as a sufficient starting point.
  • R06 From the study, the set of features in common and, beyond it, the features unique to one program or another, to reach the most ambitious feature set.

The refinement core

  • R07 A core that performs the refinements.

Graphics

  • R08 A graphical part to watch the refinement evolve, cycle by cycle, as FullProf does (observed, calculated, difference, reflection markers updated at every cycle).
  • R09 A graphical part dedicated to analysing the data.
  • R10 A graphical part for analysing the results of the experiments and refinements.
  • R11 Interactive graphics: for example the selection of background points by hand, and similar operations done on the plot.

Crystallography

  • R12 Access to the complete set of space groups, with all the needed information: symmetry operators, symmetry elements, and the rest.

Control files and the editor

  • R13 A user interface that generates the control files of a refinement.
  • R14 A dedicated text editor, handy and powerful, created and adapted exclusively for editing the input control files and for reading the output files.

Beyond the list

  • R15 The features above are those the brief could think of; there are many more. Investigate, think and propose, in detail and with judgement.

How the work is done

  • R16 Log everything and report everything.
  • R17 A website that holds the whole construction process: release notes, findings, the background (the programs used as inspiration), and the manuals of the core and of the app.
  • R18 Work the same way as the difes project and its ecosystem (core, shell, ecosystem site, log, release notes, manual).
  • R19 The work is to be done in Claude; the first step is to create the repository.
