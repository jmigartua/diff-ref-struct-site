Proposal (draft)

The proposal draft, not decided

The app's feature set, and what goes in version 1, version 2 and later. Built from the FullProf inventory and the GSAS-II gap list. Each feature names its sources: an inventory entry, a gap or a requirement of the brief. Written for Josu to decide (log L019); a decision entry in the log will say what is adopted. The design questions Q1–Q6 are on the Design page.

A draft for Josu to decide, not a decision. Version 1 aims at the refinement a FullProf user does today on constant-wavelength data (laboratory X-rays, synchrotron, reactor neutrons): from the pattern to a published CIF, in one phase or several, with constraints and restraints. It runs inside the Mac app the brief asks for: live plot, interactive background, space groups, control-file builder and editor (R07–R14). Version 2 adds what makes the program complete for facility work: time of flight, joint and sequential refinement, rigid bodies, anisotropic microstructure. Later holds the rest of the FullProf inventory and the L012 list (magnetic, superspace, stacking faults, indexing, structure solution, 2D images, PDF). Where GSAS-II does something better than FullProf (L014), the draft takes the GSAS-II way, and says so.

38 features in version 1, 11 features in version 2, 10 features in later.

  • Version 1 is done when the command line and the app reproduce a set of reference refinements from manuals/fullprof/ to within their esd's: the Y2O3 laboratory X-ray tutorial, the MgAl2O4 spinel, the Co-doped YBCO neutron tutorial and the quantitative-analysis tutorial. Each one becomes a named test, as difes reproduces FOCUS.
  • Every feature has a test and a command-line path in the core before it has a menu in the app (CLAUDE.md).

Kept for later (L012)

Kept for later, as set in L012: magnetic structures, modulated and superspace structures, stacking faults, indexing, structure solution, 2D image integration, PDF and total scattering. FullProf has each (one line each on the FullProf page); none is in versions 1 or 2. The data model of version 1 should not close the door to magnetic phases (moments on atoms, magnetic space groups), which FullProf users expect next.

Decided by Josu (L020, L021)

  • TOF (P05): version 2. Version 1 is constant wavelength only.
  • Joint X-ray + neutron (P06): version 2, with a data model that allows several patterns from the start.
  • Rigid bodies (P41): version 2. Distance, angle and linear restraints are in version 1.
  • The minimiser (P42): Levenberg–Marquardt with SVD against correlations, as GSAS-II.
  • The control file (P47, Q3): a new readable text format of our own, with a .pcr importer.
  • The reference refinements that define 'version 1 is done': the four tutorials named above (Y2O3, MgAl2O4, Co-doped YBCO, quantitative phase analysis).
  • Q1, the language of the core (L021): Rust, with Python as the scripting interface through bindings in version 2 (P48).
On this page

    What this is

    The working site of one project: to build a Mac app for Rietveld refinement of powder diffraction data, after a study of the programs the community uses for it. It holds the brief, that study, the design, a dated log of every step, the release notes and the manuals of the core and the app.
