Parameters: the theory

Parameters: the theory

The parameter dictionary (L044, L046): every parameter the core reads or will refine, under a readable name, with the equation it enters and where that equation comes from. The core's names, the app's help and this page are generated from the same file, so they cannot drift apart.

The papers' own equations have not yet been read against these: the session that wrote the dictionary could not reach the journals, so each equation is cited to the page where FullProf's manual or the microstructure paper prints it, and each paper's reference was checked against bibliographic records only. Where FullProf computes something other than its manual prints, the core's default follows the manual and the FullProf convention keeps FullProf's rule (L046).

102 entries, 90 refinable. Each gives the parameter's name in the core, its symbol, unit and meaning, the equation it enters with the paper behind it and the page where the equation is printed, its FullProf and GSAS-II equivalents, the range measured on the 240 .pcr files of the FullProf material that the core reads, the default, when to refine it (after FullProf's manual, p. 14) and the limits the engine holds it within. Generated from data/parameters.yml; do not edit by hand.

Radiation and instrument

Wavelength λ₁

wavelength_1 · \(\lambda_1\) · Å · refinable

The wavelength of the main line; with d it sets each Bragg angle.

\(\lambda_1 = 2 d_{hkl} \sin\theta_{hkl}\)

Equation as printed in: FullProf_Manual.pdf, p. 75. Paper: J. Rodríguez-Carvajal (2001). An introduction to the program FullProf 2000. Laboratoire Léon Brillouin, CEA-CNRS (manuals/fullprof/FullProf_Manual.pdf)

FullProf Lambda1, line 8 (manual p. 75); also the WAVE line of a parametric resolution file, which replaces it (L042)
GSAS-II Lam1 (Lam for one line; GSASIIobj.py L666, defaultIparms.py L35)
Range X-rays 0.963–1.5406 (median 1.54056, Cu Kα1); neutrons 1.227–2.524 (median 1.87)
Default none: read from the .pcr
When to refine Not for laboratory data (known); for synchrotron and neutron data with a standard, together with the zero, the cell fixed (manual p. 83: "Cell parameters should be fixed if wavelength is to be refined").
Limits Above 0.001 Å. Refined for a pattern of one wavelength only, λ₂ moving with λ₁ as FullProf writes both (FP_tests/pb_ho.pcr and eight more patterns); a doublet's is refused (FullProf refines a single wavelength, p. 83; P18, L233).
Class global (FullProf's relaxation class; believed: the manual's LINE 9 names no class for the wavelength; it is coded on line 14 beside the zero)
Largest shift per cycle none
Correlated with cell_a, cell_b, cell_c: Bragg's law fixes λ/d, not λ and d apart: a wavelength k times larger with every cell edge k times longer gives the same peak positions (only the form factors and Debye–Waller terms at s = 1/2d tell them apart, weakly). Tip: Fix the cell at a standard's values when the wavelength is refined, as the manual says (p. 83). FullProf_Manual.pdf, p. 83

Peak window

peak_window · \(W_{dt}\) · FWHM · read, not refined

The half-range over which a peak is calculated, in units of its FWHM; beyond it the profile is zero.

\(\Omega(x) = 0 \quad\text{for}\quad |x| > W_{dt}\, H\)

Equation as printed in: FullProf_Manual.pdf, p. 75. Paper: J. Rodríguez-Carvajal (2001). An introduction to the program FullProf 2000. Laboratoire Léon Brillouin, CEA-CNRS (manuals/fullprof/FullProf_Manual.pdf)

The default calculates each peak to ±Wdt·H and tapers it to zero by \(\pm\)1.25·Wdt·H, so that \(\chi^2\) is continuous as widths and positions change (L058; FullProf cuts it at the edge: Convention::window_edge). FullProf counts the window without X tan \(\theta\) for TCH and takes one more low point when X ≠ 0 (L035, L042): Convention::peak_window. No exact translation: a .pcr keeps FullProf's window on import (L050); switching it to the default moves \(\chi^2\) by up to 6.2% on the FullProf runs (YVO3, with the tapered edge, L058).
