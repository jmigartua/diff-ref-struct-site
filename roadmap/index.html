Roadmap

Phases

Study, then design, then the core, then the app around it. Each phase ends with a named artefact and a log entry. Only phase 0 is detailed; the later phases are drawn from its feature matrix and their detail is written when phase 0 closes.

PHASE 0 · closed (L022)

The repository, and the study of the programs

Know what the Rietveld programs in use do, and how, before deciding what this one will do.

  • Private repository, site skeleton, brief organised into requirements, working method in CLAUDE.md. done (L006)
  • Choose the five most used programs from the long list, with the evidence (citations, facilities, vendors): FullProf, GSAS-II, TOPAS, Jana2020, MAUD. done (L008) Limited to three, FullProf, GSAS-II and Jana2020, by Josu. L009 Jana2020 dropped, leaving FullProf and GSAS-II. L015
  • Method revised by Josu (L012): FullProf is the baseline; GSAS-II and Jana2020 are read only for what FullProf lacks. Scope: crystal-structure refinement from powder data. L012
  • The FullProf inventory: one entry per capability within the scope, what it does, its .pcr reference and its source (path, page) in manuals/fullprof/; capabilities outside the scope listed in one line each: 199 entries. done (L013, L017)
  • GSAS-II: what FullProf lacks within the scope, in physics and in workflow (projects, sequential and parametric refinement, constraints and restraints, scripting, GUI), each gap with its source: 36 gaps. done (L014, L018)
  • The proposal: the feature set of the app, what is in the first version and what comes later: draft, 59 features (38 in version 1, 11 in version 2, 10 later), its six open questions decided by Josu (L020); Q1, the core's language: Rust, with a Python interface (L021). L019–L021
Done when the FullProf inventory and the GSAS-II gap list are on the site, and the design questions Q1–Q6 each have a logged decision.
PHASE 1 · closed (L035)

Crystallography core

Space groups, unit cells, reflections, structure factors, in Rust (L021), each tested against an independent source: FullProf's own output files in manuals/fullprof/, spglib, the International Tables.

  • The crate drs (library and command line), and the unit cell: metric tensors, reciprocal cell, volume, d(hkl), 2\(\theta\), Cartesian frame, Busing–Levy matrix. Test fullprof_metric: all 13 FullProf .out files, no disagreement. done (L023, core 0.1.0)
  • Space groups from Hall symbols: the 230 types in their 530 settings, symmetry operators, centring, Laue class, point group; each checked against spglib and the International Tables, Vol. A. Tests spglib_530 (all 530 settings, 7388 operators, no disagreement) and fullprof_spacegroups (all 13 FullProf .out files); the International Tables not checked directly. done (L024, core 0.2.0)
  • Wyckoff positions and site symmetry: multiplicities, and the constraints on coordinates and displacement parameters of atoms on special positions, as FullProf derives them. Tests spglib_wyckoff (every Wyckoff position of the 230 standard settings), fullprof_sites (96 multiplicities and 69 anisotropic atoms of the FullProf files), crysfml_symbols. done (L026, core 0.3.0)
  • Reflections: the hkl list within a d or 2\(\theta\) range, systematic absences, multiplicities, equivalent reflections; checked against FullProf's reflection lists for the tutorial structures. Tests fullprof_reflections (9 phases, 14337 reflections, same h k l, multiplicities, d and 2\(\theta\)) and reflection_properties (all 530 settings). done (L028, core 0.4.0)
  • Structure factors: X-ray form factors and anomalous terms, neutron scattering lengths, occupancies, isotropic and anisotropic displacements; checked against FullProf's structure factors for the four reference structures (Y2O3, MgAl2O4, Co-doped YBCO, the QPA phases). Tests fullprof_structure_factors (12026 F\(^{2}\) printed by FullProf for PPH3, citric acid and LaMnO3), gemmi_structure_factors (the four reference structures, 10 phases, X-rays and neutrons, against gemmi), structure_factor_properties (530 settings), cif_structures; drs sf. FullProf's own structure factors (Hkl = −3) of the five reference runs: test fullprof_reference_sf, 11 phases, 1992 reflections, F real and imaginary within FullProf's print and single precision. done (L030, core 0.5.0; L035, core 0.7.0)
Done when the reflections and structure factors of the four reference structures of L020 agree with FullProf's output, from the command line. Met: the reflections (L028) and FullProf's own structure factors of the five reference runs (L035).
PHASE 2

The powder pattern and the refinement

Everything of version 1 (L019, L020) that computes and refines, in the core and on the command line: the calculated pattern, then the least-squares engine around it. The app's features (project document, builder, editor, live plot, graphics: P46, P48–P52, P58) are phase 3. Each step is tested against FullProf: the calculated patterns of its .prf files (85 in manuals/fullprof/), and the four reference tutorials run with FullProf on the Mac.

  • Reading the inputs: FullProf .pcr files (import, Q3) and the data formats of P02 (xy/xye, FullProf's free and instrument formats, GSAS fxye, Panalytical .xrdml, Bruker .raw/.brml), with \(\sigma\) and variable step (P01). Modules pcr (all 151 tutorial .pcr files read; one pattern, constant wavelength) and data (Ins 0, 1, 3, 5, 6, 8, 10, 12); test fullprof_profiles reads the observed data of 80 .prf files as FullProf read them (301429 points, Ins 3, 6, 10). The material holds no .xrdml, .raw or .brml file: those readers wait for an example. done (L033, core 0.6.0)
  • The calculated pattern, as FullProf computes it: peak positions with zero, displacement and transparency (P18); pseudo-Voigt and Thompson–Cox–Hastings profiles with Caglioti widths, Finger–Cox–Jephcoat axial asymmetry and the empirical asymmetry (P15, P17); the instrumental resolution file (P16); Lorentz–polarisation by geometry (P27); background functions (P21); several phases with their scales (P32); simulation with Poisson noise (P04). Checked point by point against Ycal and Backg of FullProf's .prf files. Test fullprof_profiles: 14 .prf files rebuilt from their .pcr, among them the five FullProf runs of the reference refinements (rms relative deviation beyond FullProf's print 2·10\(^{-5}\) to 5·10\(^{-4}\), \(\chi^{2}\) as FullProf's to 0.15%), a Le Bail fit to 2.7·10\(^{-3}\), one .prf not drawn from the state of its .pcr; the others left out with their reason; drs calc, drs simulate. Two FullProf rules not found (the reflection limit past the data, the last 0.06–2.7% of the window when \(X \neq 0\)). done (L033, core 0.6.0; L035, core 0.7.0)
  • Sample terms: isotropic size and strain over the resolution file (P24), preferred orientation along one axis (P28), absorption and microabsorption (P29). Size and strain: module microstructure, drs mic, test fullprof_microstructure (the widths of 9 FullProf runs, 2710 reflections; every row of three .mic files); absorption, Lorentz–polarisation and March–Dollase preferred orientation: test fullprof_corrections (1707 reflections of 11 runs, with Yb2ZrWO8-PO-March, L042); the exponential function has no FullProf reference and surface microabsorption is refused. The peak window: CrysFML's low edge and the parametric resolution file's wavelengths and asymmetry found, the 35 FullProf window experiments compared in fullprof_profiles, 23 with no point set apart (L042); YVO3 at Wdt = 40, the rutile-anatase and MgAl2O4 window edges and 15 points of 12 experiments still differ by rules not found, frozen and listed for Josu. partly done (L039, core 0.8.0; L042, core 0.9.0)
  • The least-squares engine: named parameters (P37), constraints and the automatic symmetry constraints (P38), limits (P39), distance, angle and linear restraints (P40), Levenberg–Marquardt with SVD and analytic derivatives (P42), every cycle reported as an event (Q5), agreement factors and statistics (P43), covariance and the esd of any derived quantity (P44). Modules dual, jacobian, refinable, lsq and drs refine: the codewords of a .pcr become parameters named by the dictionary, with constraints, symmetry constraints and limits, refined by Levenberg–Marquardt on an eigen-decomposition with exact derivatives (test engine_derivatives). Test fullprof_refinements: from the tutorials' starting files, Y2O3, Yb2ZrWO8, MgAl2O4, the Egyptian make-up and rutile + anatase reach FullProf's \(\chi^2\) with every parameter within FullProf's esd; Co-YBCO reaches a lower \(\chi^2\) than FullProf, whose last point is not a minimum; LaB6's window, NdNi-HTO's magnetic phase and YVO3's divergence in FullProf are explained or reported and frozen, with FullProf's halved cell esd's under TCH, for Josu. Restraints (P40) are still to do. partly done (L053, core 0.12.0)
  • Le Bail fit with extracted intensities (P35); quantitative phase analysis with esd's (P33); automatic background points (P22, the core's part). to do
  • The parameter dictionary (L044): one entry per parameter with a readable name, symbol, unit, meaning, equation and its paper, the FullProf and GSAS-II equivalents, range, default and when to refine it; the single source for the core's names, the app's tooltips, the editor's help and the manual's theory. Before the control file. data/parameters.yml, 45 entries, rendered as Parameters: the theory and generated into the core's parameter_table; test parameter_dictionary (every field of Model, Phase, Atom mapped). The papers' references were checked against bibliographic records; their equations were not read (no access from the session). done (L046, core 0.10.0)
  • The default model versus the FullProf-compatibility layer (L043): each rule accepted in L036–L042 checked against its original paper; where FullProf departs from it, the paper's form becomes the default and FullProf's stays in the compatibility layer. powder::Convention, rule by rule: the six papers in manuals/papers/ decide the defaults (Bérar & Baldinozzi's F_b and sign, Finger–Cox–Jephcoat's S/L and H/L, Dollase's exponential and the average over equivalent reflections, TCH and Caglioti unchanged), and importing a .pcr translates its values exactly (scale \(\times 2\), P1 + 3P2, G1 → −G1, the axial pair, the excluded regions), keeping FullProf's peak window and reflection range, which have no exact translation; test default_convention: 47 FullProf runs imported, \(\chi^2\) unchanged. done (L050, core 0.11.0)
  • Our own readable control file, written and read by the core (P47, Q3); the outputs: CIF ready for deposition, listing, reflection lists, profiles per phase (P57); distances, angles and bond-valence sums (P12). to do
Done when the four reference refinements of L020 (Y2O3, MgAl2O4, Co-doped YBCO, the quantitative-analysis tutorial) are reproduced from the command line, from FullProf's starting files, to within FullProf's esd's.
PHASE 3

The Mac app

The Tauri window: menus, documents, the live plot, the interactive background, the control-file builder and the editor.

  • A walking skeleton, early and alongside phase 2 (L044): a Tauri window that opens a .pcr, calls the core as a library (no server), and draws Yobs, Ycal, the difference and the reflection markers. Built on the Mac, since a cloud session cannot build the app. done (L049, app 0.1.0)
On this page

    What this is

    The working site of one project: to build a Mac app for Rietveld refinement of powder diffraction data, after a study of the programs the community uses for it. It holds the brief, that study, the design, a dated log of every step, the release notes and the manuals of the core and the app.
