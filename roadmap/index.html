Roadmap

Phases

Study, then design, then the core, then the app around it. Each phase ends with a named artefact and a log entry. Only phase 0 is detailed; the later phases are drawn from its feature matrix and their detail is written when phase 0 closes.

PHASE 0 · closed (L022)

The repository, and the study of the programs

Know what the Rietveld programs in use do, and how, before deciding what this one will do.

  • Private repository, site skeleton, brief organised into requirements, working method in CLAUDE.md. done (L006)
  • Choose the five most used programs from the long list, with the evidence (citations, facilities, vendors): FullProf, GSAS-II, TOPAS, Jana2020, MAUD. done (L008) Limited to three, FullProf, GSAS-II and Jana2020, by Josu. L009 Jana2020 dropped, leaving FullProf and GSAS-II. L015
  • Method revised by Josu (L012): FullProf is the baseline; GSAS-II and Jana2020 are read only for what FullProf lacks. Scope: crystal-structure refinement from powder data. L012
  • The FullProf inventory: one entry per capability within the scope, what it does, its .pcr reference and its source (path, page) in manuals/fullprof/; capabilities outside the scope listed in one line each: 199 entries. done (L013, L017)
  • GSAS-II: what FullProf lacks within the scope, in physics and in workflow (projects, sequential and parametric refinement, constraints and restraints, scripting, GUI), each gap with its source: 36 gaps. done (L014, L018)
  • The proposal: the feature set of the app, what is in the first version and what comes later: draft, 59 features (38 in version 1, 11 in version 2, 10 later), its six open questions decided by Josu (L020); Q1, the core's language: Rust, with a Python interface (L021). L019–L021
Done when the FullProf inventory and the GSAS-II gap list are on the site, and the design questions Q1–Q6 each have a logged decision.
PHASE 1 · closed (L035)

Crystallography core

Space groups, unit cells, reflections, structure factors, in Rust (L021), each tested against an independent source: FullProf's own output files in manuals/fullprof/, spglib, the International Tables.

  • The crate drs (library and command line), and the unit cell: metric tensors, reciprocal cell, volume, d(hkl), 2\(\theta\), Cartesian frame, Busing–Levy matrix. Test fullprof_metric: all 13 FullProf .out files, no disagreement. done (L023, core 0.1.0)
  • Space groups from Hall symbols: the 230 types in their 530 settings, symmetry operators, centring, Laue class, point group; each checked against spglib and the International Tables, Vol. A. Tests spglib_530 (all 530 settings, 7388 operators, no disagreement) and fullprof_spacegroups (all 13 FullProf .out files); the International Tables not checked directly. done (L024, core 0.2.0)
  • Wyckoff positions and site symmetry: multiplicities, and the constraints on coordinates and displacement parameters of atoms on special positions, as FullProf derives them. Tests spglib_wyckoff (every Wyckoff position of the 230 standard settings), fullprof_sites (96 multiplicities and 69 anisotropic atoms of the FullProf files), crysfml_symbols. done (L026, core 0.3.0)
  • Reflections: the hkl list within a d or 2\(\theta\) range, systematic absences, multiplicities, equivalent reflections; checked against FullProf's reflection lists for the tutorial structures. Tests fullprof_reflections (9 phases, 14337 reflections, same h k l, multiplicities, d and 2\(\theta\)) and reflection_properties (all 530 settings). done (L028, core 0.4.0)
  • Structure factors: X-ray form factors and anomalous terms, neutron scattering lengths, occupancies, isotropic and anisotropic displacements; checked against FullProf's structure factors for the four reference structures (Y2O3, MgAl2O4, Co-doped YBCO, the QPA phases). Tests fullprof_structure_factors (12026 F\(^{2}\) printed by FullProf for PPH3, citric acid and LaMnO3), gemmi_structure_factors (the four reference structures, 10 phases, X-rays and neutrons, against gemmi), structure_factor_properties (530 settings), cif_structures; drs sf. FullProf's own structure factors (Hkl = −3) of the five reference runs: test fullprof_reference_sf, 11 phases, 1992 reflections, F real and imaginary within FullProf's print and single precision. done (L030, core 0.5.0; L035, core 0.7.0)
Done when the reflections and structure factors of the four reference structures of L020 agree with FullProf's output, from the command line. Met: the reflections (L028) and FullProf's own structure factors of the five reference runs (L035).
